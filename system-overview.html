系統設計說明

讓業務員在客戶現場 30 秒內完成產品查詢與報價，取代「翻紙本型錄 + 打電話回公司」的流程。本文說明搜索邏輯、卡片設計，以及目前 Demo 如何銜接完整系統開發。

📅 2026-05-29 🔗 線上 Demo：leonardo101101078-beep.github.io/laitin-search-v2
1搜索設計

搜索邏輯如何設計？如何對應原始資料

把「找產品」拆成兩種互補方式 — 打字即時找 + 條件篩選 — 兩者同時生效、取交集，一邊打字一邊縮小範圍。

資料基礎：Excel 三色分層

系統的單一事實來源是產品資料庫 Excel。欄位依角色分成三色，這是整套系統的地基 — 搜索條件與卡片欄位全部由資料自動長出來，不是寫死的。

🔵 藍 · 共通核心
三系列都有的欄位 系列、主標、副標、簡述、主型號、標籤、零售價
→ 搜索與卡片的主幹
🩷 粉 · 系列獨有
每系列各自不同的規格 鋁線槽：底/高/燈槽寬
燈帶：電壓/功率/防水等級
→ 動態生成專屬篩選器
🔴 紅 · 內部定價
牌價/批發/工程/優惠/單位 本期完全不進系統
→ 未來依帳號層級才顯示
📦 目前三個系列、抽樣 53 筆代表性產品：鋁線槽系列 15、燈帶控制器系列 14、輕智能系列 24。日後 Excel 新增系列或欄位，系統能自動對應。
🔍 搜索入口（v0.5）：點右上角放大鏡即可隨時叫出搜索面板 — 內含「一般搜索」與「進階搜索」，不必捲回頁面頂端；整頁只有這一個搜索入口，操作一致。

第一種找法 — 一般搜索（打字即時找）

  • 輸入後 ≤100ms 即時更新，不必按搜索鍵。
  • 比對白名單：主型號、品項名稱、型號、簡述、標籤、副標。
  • 支援數值範圍：輸入「70」會命中規格寫「50~90」的產品。

第二種找法 — 進階搜索（兩段式條件篩選）

1
先選「系列」鋁線槽 / 燈帶控制器 / 輕智能 — 必選
2
共通篩選主標 → 副標 → 零售價區間（＋全部系列時的「全部標籤」）
3
系列獨有屬性（選了系列才展開）該系列「標籤」＋ 依規格自動生成的欄位
  • 標籤跟著系列走（v0.5 依回饋優化）：選了系列，標籤移到「系列獨有屬性」最上方只列該系列標籤；全部系列時在共通區顯示全部 — 不再一次冒出 200 多種。
  • 同欄位選多項 = 全部都要符合（AND）：越選越精準。
  • 動態顯示：規格欄位若整系列只有一種值就自動隱藏。
  • 下拉筆畫排序：數字 → 中文（筆畫少到多）→ 英文 A–Z。
最終顯示 = 一般搜索結果 ∩ 進階搜索結果。 沒選的條件不約束；選了具體值則空值產品排除。
⚡ 搜索完全在使用者瀏覽器內運算，不呼叫任何 AI、不耗任何費用 — 用幾次都不花錢。

卡片頁面如何設計（縮圖 + 詳情）

分成「列表縮圖卡」與「點開後的詳情 Modal」兩層，v0.4 依試用回饋大幅優化。

列表縮圖卡

  • 圖片固定 4:3 橫向置中，不裁切變形；空白處淺灰補滿、整排對齊。
  • 層級精簡：主標（大字）→ 副標（藍底標籤）＋ 型號同行 → 簡述 → 標籤。
  • 庫存（左）與價格（右）置於卡片底部，業務一眼看到有沒有貨、多少錢。

詳情 Modal（背景列表不跑掉）

  • 上方：主標 + 副標 + 簡述 + 庫存。
  • 中間：產品大圖，往下滑時圖片黏在頂部持續可見。
  • 規格表：從「品項名稱」起、空白欄位不顯示、隔行深淺底色、標籤排最後。
  • 左右切換相鄰產品：手機滑動、桌面箭頭 / 鍵盤，比價快速。
  • 價格預設遮蔽，點擊才顯示、關閉自動藏回 — 保護報價隱私。
⚠️ 目前 Demo 的多層價格為示意用假價（由零售價推算 5 層級）。真實底價待後端串接後，依登入帳號層級顯示。
3後續開發

目前是 Demo，後續如何接上完整 PRD 開發

目前版本定位是「可驗證的互動原型」：先把體驗與規則確認到位，避免後端做下去才發現方向錯誤。

現在 Demo 的樣子（刻意從簡）

  • 純前端網頁 + 資料直接內嵌 — 無後端、無資料庫、零運算成本。
  • 價格是假的、無登入、無跨裝置同步。
  • 好處：改得快、隨時上線給業務試、零成本驗證。

銜接正式系統的路線（對齊 PRD）

F-01／02／03A. 後端地基Supabase 資料庫 + 登入 + 三層帳號權限
定價安全B. 真實定價底價由後端依帳號層級返回（內部／一級／二級代理商），絕不在前端過濾
F-06C. 報價流程報價清單加入／數量／小計，跨裝置同步
F-07／08D. 管理後台管理員建立帳號、Excel 批量匯入產品
F-10~12E. 加值功能收藏夾、瀏覽紀錄、圖片輪播

為什麼 Demo 不會白做

正式版直接沿用現在的搜索、卡片、Modal 邏輯，只做兩件替換：

內嵌假資料→向後端要真資料
示意假價→依帳號層級的真實底價
這個 Demo 驗證過的互動與規則，就是正式版的前端骨架。原型驗證完成後，再正式更新一版 PRD（v0.7）作為後續開發依據。
★核心承諾

三大安全與效能承諾

🔒 定價安全

底價一律由後端依帳號層級返回，前端只顯示、不過濾；API 全程驗證 Token。

⚡ 搜索效能

前端運算，≤100ms 即時更新，零運算費用。

📱 現場可用性

觸控區 ≥48px、字體 ≥17px、高對比（戶外強光可讀）、手機優先。
