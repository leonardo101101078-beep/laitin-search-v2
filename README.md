# 萊廷照明 — 篩選器原型 v2

> 此 repo 僅作為篩選器原型 v2 的線上預覽，內容不含內部定價、客戶工程圖、PRD 等敏感資料。

## Demo

請見 GitHub Pages：<https://leonardo101101078-beep.github.io/laitin-search-v2/>

## 原型內容

- **一般搜索**：料號 / 品名 / 描述 / 標籤 即時匹配，含範圍欄位（如「85~265」）數值命中
- **進階搜索**：系列 → 主標 → 副標 三層連動，加上動態載入的系列獨有屬性
- **動態欄位**：依資料推導數值範圍 / 多選 chips 控件，少於 2 種值的欄位自動隱藏
- **產品 Modal**：詳細規格、零售價（點擊才顯示）、Lightbox 圖片放大

## 樣本資料

內嵌 53 筆代表性 SKU，涵蓋三系列：

- 鋁線槽系列（15 筆）
- 燈帶控制器系列（14 筆）
- 輕智能系列（24 筆）

紅色欄位（牌價、批發價、工程價、本月優惠價、單位）依設計**不入 JSON**。
